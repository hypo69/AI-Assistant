# Навык: Универсальное модальное окно ИИ-ассистента (AI Modal Dialog)

**Updated:** 2026-11-01 17:35:00

## 📌 Назначение и концепция

Универсальное модальное окно ИИ-ассистента (`#universal-ai-table-modal`) — ключевой компонент WebGUI в проекте **AI-Assistant** (`apps/ai_assistant/api/webgui/ai_modal_dialog/` и `apps/common/webgui/ai_modal_dialog/`). Оно обеспечивает сквозной контекстный ИИ-анализ любых сущностей проекта (версий файлов, коммитов Git, документов рабочей области, извлеченных фактов, заметок Obsidian, писем Gmail и плагинов) с многоуровневой архитектурой:

1. **L1 Exact Cache (WikiLLM / SQLite)**: мгновенный возврат верифицированных карточек знаний без ожидания обращения к LLM.
2. **Contextual LLM Explanation**: генерация структурированного ответа (краткое резюме, ключевые изменения/факты, семантические связи, рекомендации) через `UnifiedChatModel` (Gemini / AGY / Ollama / OpenAI / Foundry).
3. **Web Grounding**: онлайн-проверка внешних фактов при необходимости.
4. **Follow-up Chat**: интерактивный чат внутри модального окна для уточняющих вопросов пользователя по выбранному файлу, коммиту или документу.
5. **Изолированные промпты по панелям и сущностям**: привязка шаблонов промптов и системных инструкций к конкретному `panelId` и `tableType` с поддержкой мультиязычности (`ru`, `en`, `he`, `uk`).

## 📐 Формальные стандарты геометрии и RTL

1. **Единый размер 90vw × 90vh (`WEBGUI.md` § 5.4)**:
   - Все модальные окна (включая `#universal-ai-table-modal` и `#universal-ai-prompt-editor-modal`) подчиняются глобальному правилу `.modal .modal-dialog` в `components.css`: ширина `90vw`, высота `90vh`, центрирование по экрану.
   - Запрещено переопределять ширину или высоту модального окна локальными стилями.
2. **Поддержка RTL (`WEBGUI.md` § 5.5)**:
   - В RTL-языках (иврит, `html[dir="rtl"]`) кнопка закрытия `.btn-close` располагается в левом углу шапки, а все поля ввода внутри модального окна (`#uai-chat-input`, поля редактора промптов) читаются и заполняются справа налево.

## 🏗️ Архитектура и DOM-структура

Модальное окно инкапсулировано в динамически создаваемый контейнер `#universal-ai-table-modal` и вспомогательное окно `#universal-ai-prompt-editor-modal`.

### Основные DOM-элементы `#universal-ai-table-modal`

| Селектор | Назначение | Описание |
|---|---|---|
| `#uai-modal-icon` | Иконка сущности | Эмодзи или SVG (`📄`, `🔀`, `📌`, `✉️`, `🧩`) |

| `#uai-modal-ai-section` | Карточка ИИ-анализатора | Блок сгенерированного ответа модели |

## 💻 Справочник JavaScript API

### Метод `window.AIModalDialog.show(options)`

Главный универсальный метод открытия модального окна для любой строки таблицы, файла в дереве или карточки документа:

```javascript
window.AIModalDialog.show({
  icon: '📄',
  title: 'contract_2026.docx',
  subtitle: 'Рабочая область: legal_docs | Ревизия: a1b2c3d',
  panelId: 'panel-files',
  tableType: 'document', // 'document' | 'commit' | 'fact' | 'email' | 'plugin' | 'generic'
  badges: [
    { text: 'Tracked (In-Place)', class: 'ui-badge ui-badge-success' }
  ],
  metadata: [
    { label: 'Полный путь', value: '\\\\WORK-PC\\C:\\Docs\\contract_2026.docx', isCode: true, fullWidth: true },
    { label: 'Извлечено фактов', value: '18' },
    { label: 'Последний коммит', value: '2026-11-01 14:20:00' }
  ],
  rawTitle: 'Метаданные и дифф последней ревизии',
  rawContent: JSON.stringify(docData, null, 2),
  requestData: docData,
  autoRun: false
});
```

## 🖱️ Стандарты событий UI

1. **Единый синглтон**: Все вызовы ИИ-анализа во вкладках и контекстном меню дерева файлов (`ide_tree_context_menu.js`) направляются строго в `window.AIModalDialog.show({...})`. Запрещено создавать дублирующие локальные модальные окна анализа.
2. **Изоляция кнопок действий в строках таблиц**: Кнопки быстрых действий внутри строки таблицы помечаются классом `no-modal-trigger` и используют `event.stopPropagation()`, чтобы клик по кнопке не вызывал открытие модального окна всей строки.
