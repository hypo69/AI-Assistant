# 🧭 Навык: Автоматическое поддержание меню панелей и блоков WebGUI (`webgui-menu-maintainer`)

Данный навык предписывает агенту обязательный регламент проектирования, генерации, аудита и автоматического поддержания меню переключения панелей субвкладок (Уровень 1) и подменю блоков (Уровень 2) на всех страницах и вкладках веб-интерфейса `AI Assistant` и `TC WebGUI`.

---

## 🎯 Архитектурный канон меню

Любой составной экран WebGUI, имеющий разделы, панели или подблоки, обязан следовать 5 нерушимым принципам:

### 1. Принцип «Меню — всегда меню»
- **Визуальный стиль:** Все пункты меню оформляются как кнопки `btn btn-sm btn-outline-primary d-flex align-items-center gap-1.5 py-1 px-2.5 rounded` (или `btn-outline-secondary` для блоков Уровня 2).
- **Позиционирование:** Меню панелей располагается в отдельном `<div>` **ПОД заголовком вкладки, строго СЛЕВА**, с разделителем `border-bottom border-secondary border-opacity-25 pb-2 mb-3`.
- **Обязательный комментарий в разметке:**
  ```html
  <!-- Блок меню переключения панелей на вкладке. Выбранная панель добавляется в url -->
  ```

### 2. Двухуровневая маршрутизация URL
Каждое переключение обязано синхронизироваться с URL через `history.replaceState` без перезагрузки страницы:
- **Уровень 1 (Панели / Субвкладки):** `#tab-<tabId>#<panelId>`
- **Уровень 2 (Блоки внутри панели):** `#tab-<tabId>#<panelId>#block-<blockId>`
- **С рабочим пространством:** `#tab-workspace#<panelId>#block-<blockId>#workspace=<workspaceId>`

### 3. Тултипы: «Делать сразу, БЕЗ обращения к модели»
> [!IMPORTANT]
> **Категорический запрет на использование LLM/AI для всплывающих подсказок навигации:**
> - Тексты тултипов формулируются и прописываются **СРАЗУ при верстке компонента**;
> - **Никаких асинхронных запросов к модели** или спиннеров ожидания при наведении;
> - Подсказка срабатывает **мгновенно** через статический `title="..."` и `data-i18n-title="..."`.
> - Текст тултипа емко объясняет:
>   1. Что открывает данный пункт меню/блок;
>   2. Какое действие или режим активируется при клике.

### 4. Строгий запрет хардкода и концепция i18n
Ни одной «сырой» строки в HTML и JS!
- Текст кнопки: `data-i18n="<keyLabel>"`
- Всплывающая подсказка: `data-i18n-title="<keyTitle>"`
- Обе записи обязаны присутствовать во всех 4 языковых словарях (`ru.json`, `en.json`, `he.json`, `uk.json`).

### 5. Перетаскиваемость (Drag & Drop) и локальный menu_config.json
- Каждая вкладка с меню обязана хранить файл `menu_config.json` непосредственно в каталоге своей вкладки;
- Все кнопки меню поддерживают перетаскивание мышью влево <-> вправо (`menu_dnd.js`, `draggable="true"`);
- Порядок кнопок кэшируется в `localStorage` и может сохраняться на сервер через `PUT /api/v1/tabs/{tab_id}/menu-config`.

### 6. Изоляция запросов: Active-Only API Fetching
- Неактивная панель или блок **НЕ ДОЛЖНЫ опрашивать API**;
- Запрос выполняется исключительно при переключении на активный экран;
- При уходе фоновые поллеры деактивируемого экрана останавливаются (`clearInterval`).

## 🛠 Автоматический аудит и генерация меню

В состав навыка входит инструмент аудита и шаблонизации:

```powershell
# 1. Аудит всех меню вкладок на соответствие стандарту:
py .agents/skills/webgui-menu-maintainer/scripts/menu_auditor.py audit

# 2. Аудит конкретной вкладки:
py .agents/skills/webgui-menu-maintainer/scripts/menu_auditor.py audit --tab tab_workspace

# 3. Автоматическое исправление нарушений (--fix) / миграция меню:
py .agents/skills/webgui-menu-maintainer/scripts/menu_auditor.py fix
# или
py .agents/skills/webgui-menu-maintainer/scripts/menu_auditor.py audit --fix

# 4. Установка Git pre-commit хука контроля меню:
py scripts/install_git_hooks.py

# 5. Регрессионная проверка через pytest:
pytest tests/test_webgui_menu_maintainer.py

# 3. Генерация шапки и меню панелей с тултипами и i18n:
py .agents/skills/webgui-developer/scripts/subtabs_builder.py generate `
  --title "Заголовок" `
  --subtitle "Подзаголовок" `
  --icon "📦" `
  --prefix "my_mod" `
  --tabs "tab1:'Обзор':bi-card-checklist:'Просмотр каталога' tab2:'Настройки':bi-gear:'Конфигурация модуля'"

# 4. Генерация подменю блоков внутри панели:
py .agents/skills/webgui-developer/scripts/subtabs_builder.py generate-blocks `
  --prefix "my_mod" `
  --blocks "view:'Таблица':bi-table:'Отображение данных' edit:'Редактор':bi-pencil:'Правка записей'"
```

## 📋 Чек-лист агента при изменении или создании экранов

Перед завершением любой задачи по WebGUI агент обязан проверить:
- [ ] Меню панелей расположено под заголовком вкладки, слева, в отдельном `div` с `border-bottom`;
- [ ] Присутствует комментарий `<!-- Блок меню переключения панелей на вкладке. Выбранная панель добавляется в url -->`;
- [ ] Кнопки имеют класс `btn btn-sm btn-outline-primary` (для субпанелей) или `btn-outline-secondary` (для блоков);
- [ ] У каждой кнопки заданы атрибуты `data-panel-id` или `data-block-id="block-<id>"`;
- [ ] У каждой кнопки прописаны `data-i18n`, `data-i18n-title` и дефолтный статический `title`;
- [ ] Текст подсказки информативен и не обращается к AI-модели;
- [ ] Ключи добавлены во все 4 словаря локализации (`ru.json`, `en.json`, `he.json`, `uk.json`);
- [ ] В `main.js` реализованы функции `updateUrlWithPanel` / `switchSubTab` с поддержкой `block-<id>`;
- [ ] В каталоге вкладки создан `menu_config.json` с описанием кнопок и `draggable: true`;
- [ ] Кнопки меню поддерживают горизонтальное перетаскивание (Drag & Drop);
- [ ] Запросы к API выполняются по принципу Active-Only.
