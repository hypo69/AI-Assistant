# Справочник API tab-core.js

Файл: `apps/windows/api/webgui/js/tab-core.js`

`tab-core.js` — единственный источник правды для переключения вкладок, управления их жизненным циклом и фонового опроса телеметрии.

---

## 📌 Главные функции

### 1. `switchTab(tabId)`
Переключает интерфейс на указанную вкладку.
- Если передано имя без префикса (например, `'system-inspector'`), префикс `tab-` добавляется автоматически (`'tab-system-inspector'`).
- Автоматически закрывает открытые боковые шторки Offcanvas (`appsSideNavOffcanvas`, `leftSideNavOffcanvas`).
- Обновляет текст и бейдж активного раздела (`#active-tab-title-badge`).
- Снимает класс `active show` с предыдущей вкладки и присваивает его новой.
- Останавливает все периодические опросники деактивированной вкладки.
- Вызывает хук деактивации `window.deactivate<OldName>Tab?.()`.
- Запускает опросники активированной вкладки и вызывает хук `window.init<NewName>Tab?.()`.

### 2. `registerTabPoller(tabId, pollerFn, intervalMs, options)`
Регистрирует периодический опрос API, который работает **ТОЛЬКО** пока указанная вкладка открыта на экране и окно браузера активно.

**Параметры:**
- `tabId` (*string*): Идентификатор вкладки (например, `'tab-services'` или `'services'`).
- `pollerFn` (*async Function*): Функция запроса данных и обновления UI.
- `intervalMs` (*number*): Интервал опроса в миллисекундах (рекомендуется от 2000 до 10000).
- `options` (*Object*, опционально):
  - `immediate` (*boolean*): Запустить ли опрос немедленно при вызове (по умолчанию `true`).
  - `pollerId` (*string*): Имя опросника, если на вкладке их несколько (по умолчанию `'default'`).

### 3. `setTabPollerEnabled(fullPollerId, isEnabled)`
Включает или выключает конкретный опросник (например, по тумблеру пользователя «Live-режим»).

### 4. `isTabActive(tabId)`
Возвращает `true`, если вкладка в данный момент открыта пользователю, и вкладка браузера не скрыта (`!document.hidden`).

### 5. `loadTab(name, htmlUrl, jsUrl)`
Выполняет асинхронную загрузку HTML и JS файлов вкладки по требованию (Lazy Load), внедряет DOM разметку в `#mainTabContent` и выполняет инициализацию.

### 6. `setupTabClicks()`
Навешивает единый глобальный делегированный обработчик клика на все элементы страницы с атрибутом `data-tab`. Вызывается **один раз** при загрузке оболочки.
