# WebGUI Developer Skill

Навык разработки, архитектурных стандартов и кодогенерации для веб-интерфейса `apps/windows/api/webgui`.

---

## 📦 Содержимое пакета
- `SKILL.md` — главное руководство и протокол выполнения задач.
- `scripts/scaffold_tab.py` — CLI генератор новых вкладок со стандартами проекта.
- `references/tab_core_api.md` — справочник API по `tab-core.js`.
- `references/ai_modal_api.md` — справочник API по `AIModalDialog`.
- `references/themes_and_styling.md` — руководство по дизайн-токенам, ThemeEngine и Редактору тем.
