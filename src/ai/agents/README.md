# `src/ai/agents` — Модуль автономных ReAct-агентов

**Updated:** 2026-11-01 17:35:00

Этот пакет реализует **слой исполняемых AI-агентов** платформы **AI-Assistant**.
Агенты работают по паттерну **ReAct** (Reasoning + Acting): получают запрос пользователя, самостоятельно выбирают инструменты (поиск по базе знаний, файлам, почте, Google Диску, интернету), вызывают их в цикле и возвращают структурированный результат.

---

## Структура пакета

```text
src/ai/agents/
├── __init__.py                  # Автоматическое обнаружение и реестр AGENT_REGISTRY
├── agent.py                     # Базовый ReAct-агент поиска и работы со знаниями
├── loader.py                    # Загрузчик декларативных JSON-манифестов агентов
├── mcp_client.py                # MCPClientManager — подключение MCP-серверов
├── prompts.py                   # Системные промпты для агентов платформы
├── tools.py                     # @tool-функции (web_search, rag_search, python_eval, file_read и др.)
└── README.md                    # Документация пакета
```

---

## Каталог базовых инструментов (`tools.py`)

| Инструмент | Описание |
|---|---|
| `web_search(query)` | Поиск актуальной информации в интернете через активную AI-модель |
| `rag_search(query, top_k=5)` | Семантический поиск по локальной базе знаний и документам |
| `python_eval(code)` | Безопасное выполнение математических и строковых выражений Python |
| `file_read(file_path)` | Чтение текстового файла проекта или рабочей области (до 10 000 символов) |

## MCP-клиент (`mcp_client.py`)

`MCPClientManager` — асинхронный контекстный менеджер, который подключается к MCP-серверам из секции `langchain.mcp_servers` в `config.json` и возвращает LangChain-совместимые инструменты:

```python
async with MCPClientManager() as mcp:
    mcp_tools = await mcp.get_tools()
    all_tools = native_tools + mcp_tools
```

## Правила разработки агентов

- **Один агент — одна зона ответственности.** Оптимальный набор: 3–6 специализированных инструментов.
- **Ленивая инициализация LLM.** Создавайте `_llm` только при первом вызове `_get_llm()`, а не в `__init__`.
- **Обязательный таймаут.** Всегда оборачивайте `agent.ainvoke()` в `asyncio.wait_for()`.
- **Безопасность.** Инструменты с внешними побочными эффектами (отправка писем, изменение файлов) требуют явного подтверждения пользователя.
