# 📡 Асинхронная передача телеметрии (src/telemetry)

## Описание
Пакет `src.telemetry` предоставляет оптимизированный асинхронный клиент для сбора и отправки системной телеметрии Windows в фоновом режиме.

## Основные возможности
- **Дельта-фильтрация (Delta Compression)**: отправка только изменившихся метрик системы, что существенно снижает объем трафика и нагрузку на хранилище. Ключевые показатели (CPU, GPU, RAM, диск, счетчики ошибок) передаются всегда.
- **Батчирование (Batch Flush)**: накопление метрик в локальном буфере и сброс пакетами раз в 30 секунд или по достижении установленного лимита записей.
- **Интеграция с logger.console**: системные и пользовательские уведомления выводятся напрямую в консоль без засорения основных файлов журналов.

## Использование
```python
from src.telemetry.async_client import AsyncTelemetryBatchClient

client = AsyncTelemetryBatchClient(batch_interval_seconds=30.0)
await client.enqueue_metrics({"cpu_percent": 15.2, "gpu_percent": 22.0})
```
