# 📦 Пакет внедрения зависимостей и реестра приложений (src/app)

## Описание
Пакет `src.app` реализует архитектурный принцип явного внедрения зависимостей (**Explicit Dependency Injection**) и автоматического обнаружения микроприложений экосистемы `/apps`.

## Компоненты
- `AppContainer` — центральный DI-контейнер для управления синглтонами, фабриками компонентов и горячей перезагрузки конфигурации без глобальных скрытых переменных.
- `AppRegistry` — реестр микроприложений из каталога `/apps` для их регистрации в общем веб-сервере и меню администратора.

## Использование
```python
from src.app import default_container, default_registry

# Получение зарегистрированного сервиса
db = default_container.resolve("db_adapter")

# Обнаружение установленных приложений
apps = default_registry.discover_and_register_apps()
```
