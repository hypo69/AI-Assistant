## 📋 Описание

Модульный плагин для AI Assistant, позволяющий скачивать аудиодорожки с YouTube и автоматически конвертировать их в высококачественный формат MP3 с сохранением метаданных (название, автор, обложка).

Использует:
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) — для извлечения медиапотока и метаданных.
- `ffmpeg` — для конвертации потока в формат MP3 с выбранным битрейтом (128–320 kbps) и вшивания тегов ID3.

---

## 🛠️ Инструменты ИИ (Function Calling Tools)

Плагин регистрирует для LLM-ассистентов следующие инструменты:

1. **`download_youtube_mp3`**:
   - `url` *(string, обязательный)*: Ссылка на видео YouTube (`https://www.youtube.com/watch?v=...` или `https://youtu.be/...`).
   - `quality` *(string, опционально)*: Битрейт MP3 (`"128"`, `"192"`, `"256"`, `"320"`). По умолчанию `"192"`.
   - Возвращает локальный путь к файлу `.mp3`, размер файла, длительность и метаданные.

2. **`get_youtube_video_info`**:
   - `url` *(string, обязательный)*: Ссылка на видео.
   - Возвращает название, имя автора/канала, длительность и URL обложки без скачивания.

---

## ⚙️ Настройки в WebGUI (`config.json`)

- `download_dir` — папка сохранения (по умолчанию `data/downloads/music`).
- `default_quality` — битрейт MP3 по умолчанию (`"192"` kbps).
- `embed_metadata` — вшивать метатеги ID3 (`true`).

---

## 🚀 Быстрые действия интерфейса (Actions)

- **Проверить yt-dlp и ffmpeg**: мгновенная валидация готовности окружения.
- **Скачать MP3 по ссылке**: запуск скачивания трека прямо из интерфейса WebGUI.
