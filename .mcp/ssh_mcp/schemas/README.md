# schemas/ — Pydantic-контракты и модели данных

**Описание:** Модели конфигурации хостов, спецификаций команд, стандартизированных ответов MCP и диагностических пакетов.

- `host.py` — `HostConfig`, `ConnectionInfo`
- `command.py` — `CommandDefinition`, `ParameterSpec`
- `execution.py` — `StandardMCPResponse`, `ExecutionMetrics`, `ErrorDetail`, `TaskRecord`
- `diagnostics.py` — `DiagnosticPackage`
