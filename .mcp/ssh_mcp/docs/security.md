# Безопасность SSH MCP Server

**Версия:** 1.0  
**Updated:** 2026-10-31 17:05:15

## Ключевые механизмы защиты

1. **Изоляция секретов (`CredentialManager`):**
   - В SQLite (`hosts`, `host_credentials`) хранится только ссылка `credential_ref`.
   - Пароли и приватные ключи разрешаются в памяти из защищённого хранилища.
2. **Верификация ключей хостов (`HostKeyVerifier`):**
   - В режиме `strict` неизвестные или изменившиеся отпечатки `SHA256:...` немедленно блокируются (`HOST_KEY_VERIFICATION_FAILED`).
3. **Привязка подтверждений (`ApprovalManager`):**
   - Подтверждения для `high` и `critical` операций криптографически привязаны к `(host_id, command_id, sha256(parameters))`.
4. **Очистка секретов (`SecretRedactor`):**
   - Все потоки `stdout`, `stderr`, параметры и детали аудита проходят через регулярные выражения и фильтрацию ключей перед записью в БД.
5. **Защита Remote MCP (`RemoteMCPAuthenticator`):**
   - Обязательная проверка `Authorization: Bearer <token>`, заголовка `Origin` и запрет публикации на `0.0.0.0` без TLS.
