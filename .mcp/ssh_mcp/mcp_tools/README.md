# mcp_tools/ — Каталог инструментов MCP (10 модулей)

**Описание:** Слой взаимодействия с AI-агентами (`MCP Layer`), разделённый на 10 функциональных модулей по Техническому заданию.

## Модули

1. `connection.py` — Connection Management (7 инструментов)
2. `execution.py` — Command Execution & Tasks (6 инструментов)
3. `system.py` — System Administration (7 инструментов)
4. `processes.py` — Process Management (6 инструментов)
5. `services.py` — Service Management (7 инструментов)
6. `filesystem.py` — Filesystem & SFTP Management (11 инструментов)
7. `network.py` — Network Management (7 инструментов)
8. `users.py` — User & Account Management (9 инструментов)
9. `logs.py` — Event & Log Management (5 инструментов)
10. `diagnostics.py` — Diagnostic & Telemetry (7 инструментов)
