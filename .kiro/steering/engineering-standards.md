# 🏗️ Инженерные стандарты и стиль кода

Этот файл синхронизирован с `.ai/instructions/standards/ENGINEERING.md` и `.ai/instructions/standards/WEBGUI.md`.

## Ключевые принципы

1. **Single Responsibility & Explicit DI:** Каждый модуль и класс решает одну задачу; зависимости передаются явно без глобального состояния.
2. **Early Return & Fail-Fast:** Немедленный возврат при невалидных входных данных; вложенность не более 3 уровней.
3. **Config Over Hardcode:** Все порты, пути и лимиты загружаются из `config.json` и `.env`.
4. **Запрет `None`:** В параметрах, переменных и возвращаемых значениях используются явные пустые значения (`''`, `0`, `False`, `{}`, `[]`).
5. **DRY & Prior Art Audit:** Перед созданием новой функции проверяйте `apps/ai_assistant/core/`, `apps/common/`, `src/ai/`, `src/utils/` (`.ai/instructions/standards/REUSE.md`).
6. **Лимит размера файла:** Максимум 500 строк функционального кода (+20% при необходимости). Управление каждой таблицей БД — в отдельном файле.
7. **Логирование:** Только через `from logger import logger` (и `logger.console()` для вывода в консоль без записи в файл).
8. **Шапка файла:** Обязательное обновление поля `Updated: YYYY-MM-DD HH:MM:SS` при каждом изменении файла.

## Стандарты WebGUI (`apps/ai_assistant/api/webgui/`)

- **Вкладки:** Каталоги именуются строго `tab_<tab_id>/` и регистрируются в `apps/ai_assistant/api/webgui/js/main.js` (`TABS`).
- **Темизация:** Запрещены инлайновые цвета и HEX/RGB; используются только CSS-переменные (`var(--...)`) и классы `ui-badge`.
- **Модальные окна:** Все модальные окна имеют размер `90vw × 90vh` без локальных переопределений.
- **RTL:** При выборе RTL-языка (`dir="rtl"`) все поля ввода читаются и заполняются справа налево (исключение — явный `dir="ltr"`).
- **Cache-Busting:** При изменении статики обновляется параметр `?v=YYYYMMDD_vN`.
