## 📌 Назначение проекта

**AI-Assistant** — локально-приоритетная (Local-first), носимая (USB-portable) платформа для управления рабочими областями документов, Git-версионирования файлов на месте (без принудительного копирования), извлечения структурированных фактов на нескольких языках (`ru`, `he`, `en`), построения базы знаний (SQLite + FAISS + WikiLLM + Obsidian Vault) и маршрутизации запросов между локальными и облачными провайдерами ИИ (`src/ai`).

## ✨ Ключевые возможности (`apps/ai_assistant`)

1. **Изолированные рабочие области (Workspaces) с Git:**
   - Каждая рабочая область является самостоятельным Git-репозиторием и компактным **Obsidian Vault** (`_Knowledge_Base.md`, `_Topics/`).
2. **Слежение за внешними файлами и папками на месте (`copy_to_workspace = False`):**
   - По умолчанию Git и индекс знаний следят за указанными файлами и директориями прямо на диске без их копирования в каталог рабочей области (через не-игнорируемые `.tracked.md` манифесты и текстовые слепки `.extracted_snapshots/`).
   - Копирование внутрь рабочей области выполняется только при явном включении соответствующей опции.
3. **Носимый (USB-флешка) режим с привязкой к имени компьютера (`\\<HOST_NAME>\<PATH>`):**
   - Все пути к внешним файлам и директориям сохраняются вместе с именем хоста (`host_name`) и полным квалифицированным путём `\\<COMPUTER_NAME>\<Drive>:\<Path>` в `.workspace/config.json`, `.tracked_sources.json`, SQLite (`documents`) и метаданных FAISS.
   - При переносе флешки на другой компьютер внешние файлы с прежнего ПК автоматически получают статус `other_host` («На другом ПК (`<HOST>`)»), не затираются и остаются доступными для чтения и поиска по сохранённому слепку `.snapshot`.
   - Одноимённые файлы с разных компьютеров автоматически изолируются по префиксу `<HOST>/<doc_id>`.
4. **Мультиязычный NLP, кореференция местоимений и морфологический синтез (`RU / HE / EN`):**
   - Извлечение фактов действия (`action`) и принадлежности (`possession`, включая конструкции `לדוד משה היתה חווה`).
   - Автоматическое разрешение местоимений 3-го лица (`он`, `она`, `у него`, `הוא`, `היא`, `שלו`, `he`, `she`, `his`) по предыдущему предложению.
   - Грамматически точное склонение кратких ответов по падежам (`Мама.` / `Раму.` / `Мамой.`).
5. **Гибридный поиск `RagFaissEngine` (FAISS 256D + TF) и SSE-стриминг:**
   - Сочетание 256-мерного векторного индекса `faiss.IndexFlatIP` с лексическим бустингом (TF) и потоковой выдачей ответов `POST /api/v1/ask/stream`.
6. **Единая IDE-оболочка (WebGUI + Electron / WebView2):**
   - Работает в браузере, десктопном окне **Electron** (`--engine electron`) или **WebView2** (`--engine webview2`) с поддержкой 5 тем оформления и полной RTL-адаптацией для иврита.

py -m apps.ai_assistant.main

# Запуск только веб-сервера на порту 8095
py -m apps.ai_assistant.main --no-gui --port 8095

# Запуск полного набора тестов (155 тестов)
py -m pytest apps/ai_assistant/tests -v
