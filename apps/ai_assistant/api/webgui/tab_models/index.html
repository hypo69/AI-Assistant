Настройки Microsoft Foundry
Где взять модели Foundry?

Microsoft Foundry (как и LM Studio) работает локально. Чтобы список моделей был не пустым, вам необходимо предварительно загрузить нужные GGUF или ONNX модели через интерфейс самого Foundry или CLI.

Настройки Ollama (Local)
Как добавить новые модели в Ollama?

Откройте терминал на сервере, где установлен Ollama, и выполните команду:
ollama pull llama3.1
После загрузки модель автоматически появится в выпадающем списке.

Настройки Microsoft ONNX Runtime & Olive
Аппаратное ускорение и оптимизация Olive

Microsoft ONNX Runtime использует аппаратные ускорители Windows (DirectML GPU, Qualcomm QNN NPU, CUDA). Microsoft Olive выполняет автоматическое квантование (INT4/INT8) и оптимизацию графов для максимальной скорости локального инференса.
