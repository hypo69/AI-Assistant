# Вкладка управления моделями ИИ и API-ключами (`tab_models`)

## Назначение
Основная панель для выбора активных моделей ИИ, переключения провайдеров (Google Gemini, Microsoft AI Foundry, ONNX / DirectML, Hugging Face, AGY, Ollama), тестирования генерации в реальном времени, управления квотами API-ключей и аккаунтами Google.

---

## Возможности
- **Каталог моделей и провайдеров**: Выбор активной модели, фильтрация по провайдерам, сохранение в `config.json`.
- **Избранное и заметки**: Добавление моделей в быстрый доступ, быстрые чипы и локальные заметки к моделям.
- **Интерактивное тестирование**: Отправка тестовых промптов с замером времени ответа и возможностью отмены (`AbortController`).
- **Управление ключами Gemini и AGY**: Ротация ключей, визуализация статуса квот, проверка работоспособности в модальном окне, добавление и удаление.
- **Управление аккаунтами Google**: Подключение, проверка статуса авторизации, переключение аккаунта по умолчанию.
- **Системные инструкции**: Просмотр и редактирование глобального системного промпта.
