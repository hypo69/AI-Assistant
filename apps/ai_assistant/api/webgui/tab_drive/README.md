## 📋 Описание функционала

Модуль веб-интерфейса для управления файлами и документами Google Drive:
- **Интерактивный список файлов и папок:**
  - Клик по строке файла (`onclick`) или кнопке редактирования вызывает модальное окно текстового редактора файлов (`#modal-ide-file-editor` / `openEditorModal`).
  - Поддержка чтения текстовых файлов, Markdown, исходного кода, экспорта Google Docs / Google Sheets.
  - Режим предпросмотра Markdown (`Markdown Preview`).
  - Сохранение отредактированного содержимого напрямую на Google Диск через API `/api/v1/drive/files/{file_id}/content`.
  - Для бинарных файлов (PDF, изображения, архивы) в модальном окне отображается статус и прямые ссылки на скачивание или открытие в веб-версии Google Диска.
- **Навигация по папкам:**
  - Клик по строке папки осуществляет переход внутрь директории с отображением цепочки навигации (Breadcrumbs).
- **Поиск и фильтрация:**
  - Фильтры по типам: Все, Папки, Таблицы, Документы, PDF.
  - Быстрый поиск по имени файла.
- **Загрузка и выгрузка:**
  - Загрузка локальных файлов на Google Drive через модальное окно `#modal-drive-upload`.
  - Скачивание файлов по прямой ссылке `/api/v1/drive/download/{file_id}`.
  - Удаление файлов с подтверждением.
