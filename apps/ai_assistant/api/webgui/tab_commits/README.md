# Вкладка: История коммитов (tab_commits)

Вкладка отображает историю коммитов репозитория с возможностью поиска и перехода к просмотру diff.

## Структура
- `panel_commits/`: Изолированная панель `panel-commits`, взаимодействующая с `/v1/panel/panel-commits`.
- `main.js`: Оркестратор вкладки.
- `index.html`: Разметка вкладки.
