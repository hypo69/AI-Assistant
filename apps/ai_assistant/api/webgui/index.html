Справка AI Assistant

Модуль AI Assistant (Smart Version History) предоставляет интеллектуальную историю изменений кодовой базы:

  • Git Adapter: Точные diff'ы, снимки ревизий и коммиты без галлюцинаций.
  • WikiLLM: Архитектурные связи modifies, fixes, documents.
  • RAG FAISS: Векторный и лексический поиск по diff-фрагментам с хешированием SHA-256.
  • 2-Step Verification: Защита от prompt-инъекций и утечки секретов перед фиксацией связей.
  • Universal Panels: Все панели загружаются через GET /v1/panel/{panel_id}.
