## 📋 Описание модуля

Модуль `track_sources_picker.js` — это единый переиспользуемый компонент пользовательского интерфейса для добавления внешних папок и файлов на диске в мониторинг и Git-слежение.

Используется одновременно в двух ключевых точках интерфейса:
1. `http://localhost:8002/#tab-create-workspace` (создание нового пространства);
2. `http://localhost:8002/#tab-workspace#panel-files#block-track` (включение файлов и папок в слежение в существующем пространстве).

---

## 🎯 Основные возможности

1. **Симметричная структура из двух карточек**:
   - Выбор директории (папки) для слежения на месте;
   - Выбор отдельного файла для слежения на месте.
2. **Мгновенное добавление без лишних кнопок**:
   - Кнопка «Обзор...» вызывает системный диалог через бэкенд `/api/v1/workspaces/browse-folder` или `/api/v1/workspaces/browse-file`;
   - При выборе объект немедленно передаётся в callback `onItemAdded(path, type)` и появляется в списке отслеживаемых объектов;
   - Ввод пути вручную и нажатие клавиши <kbd>Enter</kbd> также мгновенно ставит путь на учёт.
3. **Строгая интернационализация (i18n)**:
   - Все текстовые подписи и подсказки берутся из словарей через функцию `t()` и атрибуты `data-i18n`.
4. **Уникальные идентификаторы элементов**:
   - Поддерживает параметр `prefix`, обеспечивающий полную изоляцию DOM ID при внедрении на разных вкладках приложения.
