## 📋 Назначение

Модульный клиентский компонент **System Tour** предоставляет интерактивный пошаговый гид-тур по архитектуре и функциональным возможностям системы умного хранения документации `AI Assistant`:
1. **Изолированные рабочие области (Workspaces)** с индивидуальным локальным репозиторием Git (`.git`).
2. **Умное хранилище и авто-извлечение фактов** через многоязычные NLP-анализаторы (RU / HE / EN, действия и отношения обладания).
3. **Темпоральный граф знаний и онтология WikiLLM** (`valid_from`, `valid_to`, `superseded_by`, семантические связи `modifies`, `fixes`, `documents`, `caused_by`).
4. **5-этапный гибридный поиск RAG и Вопрос-Ответ** (морфологический разбор падежей и предлогов, локальный фактологический поиск в SQLite, векторный поиск FAISS и fallback на модели `src/ai`).
5. **2-Step контур безопасности** (защита от prompt-инъекций и утечки конфиденциальных данных).
6. **Аудит истории изменений** (шкала времени ревизий файлов, коммиты, построчный Diff и Smart Blame).

---

## 🚀 Программный API

Компонент доступен глобально через объект `window.SystemTour`:

```javascript
// Открыть тур с первого шага (или с указанного индекса 0..N-1)
window.SystemTour.show(0);

// Закрыть окно тура
window.SystemTour.close();

// Переход к следующему/предыдущему шагу
window.SystemTour.next();
window.SystemTour.prev();

// Переход к конкретному шагу
window.SystemTour.goToStep(2);
```

## 🎨 Дизайн и Темизация

- **CSS-токены:** Полное отсутствие хардкода цветов (HEX/RGB). Стили в `system_tour.css` строго используют CSS-переменные активной темы оформления (`var(--card-bg)`, `var(--border-color)`, `var(--surface-1)`, `var(--text-color)`, `var(--primary)` и др.).
- **Адаптивность:** Корректное отображение на экранах мобильных устройств и десктопов.
- **Управление с клавиатуры:** Навигация стрелками Влево (&larr;) и Вправо (&rarr;), закрытие по `Escape`.
