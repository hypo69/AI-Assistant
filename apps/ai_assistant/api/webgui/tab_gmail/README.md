# Вкладка «Управление почтой (Gmail)» (`tab_gmail`)

Интерфейс управления электронной почтой Gmail пользователя для WebGUI микросервиса AI Assistant (`assist.ps1`).

---

## Архитектура и возможности

- **Авторизация**: Бесшовная аутентификация через Google OAuth 2.0 (сохраненные токены в `src/secrets/google_oauth_tokens/`).
- **Сводка профиля**: Отображение email адреса пользователя, общего количества сообщений и цепочек (`getProfile`).
- **Папки и метки**: Навигация по системным папкам (Входящие, Помеченные, Отправленные, Черновики, Спам, Корзина) со счетчиками непрочитанных писем.
- **Поиск и фильтрация**: Поддержка синтаксиса поисковых запросов Gmail (`from:`, `is:unread`, `has:attachment` и др.).
- **Просмотр писем**: Рендеринг HTML/plain тела письма в изолированном фрейме с отображением прикрепленных вложений.
- **Действия**: Отметка прочитанным/непрочитанным, установка звезды (помеченное), перемещение в корзину и быстрое создание ответа (Reply).
- **Отправка писем**: Встроенный мастер написания писем с валидацией адресата, темы и поддержкой HTML-разметки.
- **Сквозная интернационализация (i18n)**: Полная локализация всех текстовых элементов, меток, подсказок (tooltips), плейсхолдеров и динамических уведомлений во всех 4 языках (`ru`, `en`, `he`, `uk`) с реактивной перерисовкой при событии `i18n:languageChanged` и локализацией дат по BCP 47.

## API Эндпоинты

- `GET /api/v1/gmail/profile` — сводная информация профиля и статистика ящика.
- `GET /api/v1/gmail/labels` — список меток и счетчиков непрочитанных писем.
- `GET /api/v1/gmail/messages` — список писем с фильтрацией и постраничной пагинацией.
- `GET /api/v1/gmail/messages/{id}` — детальный контент письма, тело и вложения.
- `POST /api/v1/gmail/messages/send` — отправка нового электронного письма.
- `POST /api/v1/gmail/messages/{id}/modify` — добавление/удаление меток (`UNREAD`, `STARRED`).
- `POST /api/v1/gmail/messages/{id}/trash` — перемещение в корзину.
