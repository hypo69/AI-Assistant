# Вкладка: Diff & Smart Blame (tab_diff)

Вкладка отображает построчный diff файлов, статистику изменений и ИИ-инсайты последствий коммитов.

## Структура
- `panel_diff_stats/`: Изолированная панель `panel-diff-stats`, взаимодействующая с `/v1/panel/panel-diff-stats`.
- `main.js`: Оркестратор вкладки.
- `index.html`: Разметка вкладки.
