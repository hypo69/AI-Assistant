## 📋 Архитектура стилей

Система стилей построена без хардкода цветов: все визуальные параметры задаются через CSS-переменные (`var(--...)`) и поддерживают 5 тем оформления (`light`, `dark`, `brick`, `terminal`, `system`) и двунаправленную вёрстку (`LTR` / `RTL` для иврита).

| Файл | Назначение |
|---|---|
| [`main.css`](main.css) | Мастер-манифест, объединяющий модули через `@import` |
| [`variables.css`](variables.css) | Базовые дизайн-токены и CSS-переменные поверхностей, текста, границ и статусов |
| [`themes.css`](themes.css) | Палитры цветовых тем (`light`, `dark`, `brick`, `terminal`) |
| [`base.css`](base.css) | Базовые стили документа, типографика, скроллбары и контейнеры вкладок |
| [`nav.css`](nav.css) | Верхняя навигация, боковой проводник IDE, переключатели тем/языков и суб-вкладки |
| [`components.css`](components.css) | Унифицированные карточки (`.ui-card`), таблицы, бейджи (`.ui-badge`), кнопки и формы |
| [`context-menu.css`](context-menu.css) | Стили контекстных меню и всплывающих умных ИИ-тултипов |
| [`rtl.css`](rtl.css) | Правила зеркалирования интерфейса, иконок, отступов и боковых панелей для иврита (`[dir="rtl"]`) |
| [`overrides.css`](overrides.css) и [`global-overrides.css`](global-overrides.css) | Согласование компонентов Bootstrap с токенами текущей темы |
| [`chat.css`](chat.css) | Стили диалоговой панели чата и карточек ответов ИИ |
