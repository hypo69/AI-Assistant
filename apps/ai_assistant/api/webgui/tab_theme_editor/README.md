# 🎨 Редактор тем оформления WebGUI (Theme Editor)

Модуль интерактивной настройки, наследования и кастомизации визуального оформления интерфейса экосистемы **AI Windows Admin** (`apps/windows/api/webgui/tab_theme_editor`).

---

## 📋 Назначение

Редактор тем предоставляет полный визуальный контроль над всеми дизайн-токенами веб-интерфейса и архитектуру наследования тем:
1. **Неизменяемые стандартные темы:** Встроенные системные темы (`Dark Slate`, `Light Enterprise`, `Cyberpunk Neon`, `Terminal` и др.) защищены от перезаписи и служат эталонными базовыми шаблонами.
2. **Наследование и дочерние темы:** Пользователь может создать любое количество дочерних тем на базе выбранной стандартной темы. Дочерняя тема наследует базовый тип (`dark`/`light`), категорию, базовые CSS-стили родителя и хранит только переопределенные токены и параметры.
3. **Размеры и геометрия:** Масштаб базового шрифта (Root Font Size), радиусы скругления углов (Border Radius) компонентов, высота карточек KPI, плотность расположения элементов (Compact / Normal / Comfortable).
4. **Цветовые палитры:** Цвета фона страницы, поверхностей карточек, шапок, меню навигации, основного и вторичного текста, акцентных цветов и состояний наведения.
5. **Границы и разделители:** Толщина, контрастность и цвета линий.
6. **Статусные цвета:** Системные цвета для бейджей и индикаторов успеха, предупреждений, критических ошибок и инфо-сообщений.
7. **Типографика и визуальные спецэффекты:** Выбор шрифтовой гарнитуры, стилей теней (Flat, Soft, Deep, Neon Glow), эффектов Glassmorphism (Backdrop blur) и кинескопных ретро-линий CRT Scanlines.
8. **Живой предпросмотр (Live Preview):** Мгновенная реакция всех компонентов интерфейса на любое изменение ползунков или цветовых палитр без перезагрузки страницы.
9. **Управление жизненным циклом дочерних тем:** Создание, сохранение, переименование, удаление и сброс параметров темы к эталонным значениям родителя.
10. **Экспорт и импорт:** Сохранение настроек в LocalStorage, скачивание и загрузка конфигураций в формате JSON, копирование готового CSS-кода в буфер обмена.

## 🏗️ Архитектура модуля

Модуль декомпозирован на панели с соблюдением стандарта `<= 500` строк функционального кода (`GEMINI.md`):

```text
apps/windows/api/webgui/tab_theme_editor/
├── index.html                  # Разметка панели настроек, Live Preview и модальных окон дочерних тем
├── main.js                     # Главный оркестратор: initThemeEditorTab, deactivateThemeEditorTab
├── README.md                   # Документация модуля на русском языке
├── common/
│   └── ui_utils.js             # Утилиты связывания DOM, селекторов колорпикеров и toast
├── panel_presets/
│   └── panel.js                # Каталог эталонных пресетов (10 тем), дочерние пресеты и статус наследования
├── panel_tokens/
│   └── panel.js                # Движок генерации CSS-токенов, импорта/экспорта JSON и CSS
├── panel_preview/
│   └── panel.js                # Живой предпросмотр (Live Preview), эффекты Glassmorphism/CRT
└── panel_actions/
    └── panel.js                # Тулбар действий (Сохранение, Создание дочерней, Сброс к родителю, Удаление, Экспорт/Импорт)
```

## ⚡ Интеграция с ядром WebGUI

### 1. Единый реестр вкладок (`core/tab-registry.js`)
```javascript
{
  id: 'theme_editor',
  label: 'Редактор тем оформления',
  icon: 'bi-palette2',
  tab: 'theme-editor',
  tabId: 'tab-theme-editor',
  html: '/html/tab_theme_editor/index.html?v=20261015_v1',
  js: '/html/tab_theme_editor/main.js?v=20261015_v1'
}
```

### 2. Конфигурация меню (`apps/modules/tabs-config.js` и `config/tc_menu_config.json`)
Вкладка зарегистрирована под ID `theme_editor` и доступна как через боковое меню, так и по прямой навигации из модального окна настроек профиля (`#userSettingsModal`).

### 3. Быстрый переход из `#userSettingsModal`
В модальное окно настроек интерфейса добавлена прямая кнопка перехода:
```html
<button type="button" class="btn btn-outline-primary btn-sm w-100" data-tab="tab-theme-editor" data-bs-dismiss="modal">
  <i class="bi bi-palette2 text-primary"></i>
  <span>Открыть редактор тем оформления</span>
</button>
```

## 🎨 Поддерживаемые пресеты оформления

- **🌑 Dark Slate (По умолчанию):** Тёмная тема сбалансированного контраста по ТЗ v2.0.
- **🏢 Light Enterprise:** Строгий высококонтрастный светлый корпоративный стиль (WCAG 2.1 AA > 7.2:1).
- **⚡ Cyberpunk Neon:** Неоновый стиль с яркими акцентами и свечением элементов.
- **👁️ High Contrast:** Максимально контрастный черно-белый стиль для специальных условий работы.
- **☀️ Light NightView:** Мягкая пастельная светлая бумага для комфортного чтения в темноте.
- **🧱 Brick Terracotta:** Тёплая кирпично-терракотовая палитра клинкерных тонов.
- **📟 Terminal Matrix CRT:** Винтажный моноширинный зеленый фосфор с CRT-сканлайнами.
- **❄️ Nordic Frost:** Скандинавский морозный синий минимализм.
- **🌲 Solarized Deep:** Классический сине-зеленый глубокий интерфейс.
