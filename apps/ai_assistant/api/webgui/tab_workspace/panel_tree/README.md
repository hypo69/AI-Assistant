# Панель виртуального и физического дерева файлов (`panel_tree`)

Модуль `panel_tree` реализует отдельную интерактивную панель дерева всех отслеживаемых Git файлов (как расположенных внутри рабочей директории, так и внешних файлов на диске вне рабочей директории) по адресу `http://localhost:8002/#tab-workspace#panel-tree`.

## Ключевые возможности
- **Виртуальные категории по содержимому (`treeViewMode = 'virtual'`)**:
  - Включает **все** отслеживаемые файлы (локальные и внешние из `.tracked_sources.json`), не требуя физического копирования внешних файлов в рабочую директорию.
  - Строит двухуровневую и многоуровневую иерархию виртуальных категорий (`Раздел / Подраздел`) на основе семантической оценки текста, извлечённых фактов (`action` / `possession`), ролей субъектов/объектов и ключевых сущностей.
- **Динамическая ревизия и переоценка категорий моделью ИИ (`POST /api/v1/workspaces/{id}/virtual-tree/revise`)**:
  - Поддерживает переключение стратегии построения категорий (`semantic_domain` — по смыслу и тематике, `fact_semantics` — по структуре фактов Действия/Владение, `entity_centric` — вокруг ключевых субъектов и сущностей) и произвольную пользовательскую инструкцию для ИИ.
  - Переоценивает содержимое файлов через модель ИИ (`UnifiedChatModel`) или корпусный семантический классификатор, сохраняя номер ревизии (`Ревизия #N`), объяснение логики построения категорий (`taxonomy_logic`) и историю ревизий в `.workspace/virtual_taxonomy.json`.
- **Устойчивость к переносу файлов без изменений (`R100` + SHA-256)**:
  - При перемещении файла во внешней папке или внутри рабочей области без изменения текста его виртуальная категория автоматически сохраняется по SHA-256 `content_hash`.
