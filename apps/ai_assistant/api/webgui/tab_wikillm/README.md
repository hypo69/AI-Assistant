# Вкладка: База знаний WikiLLM (tab_wikillm)

Вкладка отображает архитектурные сущности и связи базы знаний WikiLLM (modifies, fixes, documents).

## Структура
- `panel_wikillm/`: Изолированная панель `panel-wikillm-entities`, взаимодействующая с `/v1/panel/panel-wikillm-entities`.
- `main.js`: Оркестратор вкладки.
- `index.html`: Разметка вкладки.
