# Вкладка: 5-этапный поиск RAG & База знаний (tab_rag)

Вкладка гибридного семантического и фактологического поиска (NLP + SQLite + FAISS + LLM) по пользовательской базе знаний активной рабочей области (User Space).

## Возможности
- **5-этапный конвейер RAG:** Разбор намерения (NLP) → Поиск фактов (SQLite) → Векторный RAG (FAISS) → Верификация непротиворечивости → Синтез ответа (LLM/Morpho).
- **Селектор рабочей области:** Мгновенное переключение контекста и синхронизация с верхним навигационным меню через событие `context:changed`.
- **Доказательная база источников:** Отображение документов-первоисточников, номеров предложений, точных цитат и семантических совпадений FAISS.
- **Инспекция чанков (`panel-rag-chunks`):** Таблица сегментов документов выбранного воркспейса с SHA256 и контролем версий.

## Структура
- `panel_rag/`: Изолированная панель `panel-rag-chunks`, взаимодействующая с `GET /v1/panel/panel-rag-chunks` и `POST /api/v1/query`.
- `main.js`: Клиентский оркестратор вкладки.
- `index.html`: Разметка интерфейса вкладки.
