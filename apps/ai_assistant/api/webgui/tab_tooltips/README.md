## Назначение

Вкладка **«Редактор всплывающих подсказок»** (`tab_tooltips`) предназначена для централизованного просмотра, аудита, редактирования и персистентного сохранения статических всплывающих подсказок (`data-i18n-title`, `title`, `tooltips.kb`) во всем веб-интерфейсе системы.

## Архитектурные принципы

В соответствии с инженерным стандартом [`.ai/instructions/standards/SUBTABS_AND_BLOCKS_MENU.md`](../../../../.ai/instructions/standards/SUBTABS_AND_BLOCKS_MENU.md):
1. **«Делать сразу, БЕЗ модели»**: Все подсказки элементов навигации и управления формулируются детерминированно и сразу отображаются при наведении мыши. Вызовы LLM-модели из всплывающих подсказок полностью исключены.
2. **Одноразовый перевод**: Для мультиязычности (RU, EN, HE, UK) достаточно однократного перевода в словари локализации.
3. **Двухуровневая маршрутизация**: Меню субпанелей (`panel-catalog`, `panel-editor`, `panel-kb`, `panel-audit`) синхронизировано с URL вида `http://localhost:8002/#tab-tooltips#<panel_id>`.
4. **Интерактивный Live Preview**: Редактор позволяет видеть визуализацию подсказки в реальном времени на любом из поддерживаемых языков.

## Структура панелей

- **Каталог подсказок (`panel-catalog`)**: Таблица всех зарегистрированных подсказок, поиск по ключу/тексту, фильтр по категориям и статусу локализации (100% переведено / требует доперевода).
- **Редактор подсказки (`panel-editor`)**: Форма редактирования метаданных и текстов на русском, английском, иврите и украинском языках с кнопкой одноразового автоперевода.
- **База знаний (`panel-kb`)**: Сводный реестр терминов WikiLLM (`tooltips.kb`) и системных определений.
- **Аудит и валидация (`panel-audit`)**: Контур контроля отсутствия сырых ключей и соблюдения стандартов i18n.

## API-эндпоинты

- `GET /api/v1/tooltips` — получение реестра всех подсказок и метрик.
- `PUT /api/v1/tooltips/{key}` — сохранение переводов в словари `locales/{ru,en,he,uk}.json`.
- `POST /api/v1/tooltips/translate` — одноразовый перевод текстов.
