# Вкладка «Умная категоризация & RAG документов» (Smart Document Categorizer & RAG)

## Назначение
Модуль предоставляет полнофункциональный веб-интерфейс для:
1. Автоматического обнаружения и фонового сканирования документов пользователя (PDF, DOCX, XLSX, TXT, MD и др.) из библиотек Windows (`Documents`, `Downloads`, `Desktop`, `OneDrive`) или из произвольного указанного каталога с безопасной фильтрацией системных директорий.
2. Семантической классификации документов по базовым категориям (Финансы, Договоры, Личные документы, Работа и Проекты, Обучение, Архив) с расчетом индекса уверенности (`confidence score`).
3. Разрешения неопределенностей через **Human-in-the-Loop** (интерактивный опрос пользователя при пограничной уверенности модели с мгновенным обучением правил для папок/шаблонов).
4. Встроенного семантического и полнотекстового RAG-поиска по проиндексированным фрагментам документов на базе SQLite FTS5.

## Структура файлов
- `index.html` — разметка вкладки (Bootstrap 5 + CSS-токены тем, без тегов `<script>`, с поддержкой `data-i18n`).
- `main.js` — клиентский контроллер вкладки (`initDocCategorizerTab`, `deactivateDocCategorizerTab`, поллинг через `registerTabPoller`, рендеринг очередей и RAG-поиск).
- `README.md` — данная документация.

## REST API Контракты
- `POST /api/v1/documents/scan` — запуск фонового сканирования (`mode: "auto" | "explicit"`).
- `GET /api/v1/documents/status` — метрики, статистика категорий и статус фонового воркера.
- `GET /api/v1/documents/items` — пагинированный список документов с фильтрами по статусу и категории.
- `GET /api/v1/documents/uncertain` — очередь спорных документов для подтверждения пользователем.
- `POST /api/v1/documents/resolve` — подтверждение категории и синтез постоянных правил фильтрации.
- `POST /api/v1/documents/search` — семантический RAG-поиск по проиндексированным текстам.
