# 🧹 Вкладка: Диагностика и обслуживание Git (tab_git_maintenance)

Вкладка веб-интерфейса микросервиса AI Assistant для интеллектуальной оценки состояния репозитория Git.

## Возможности
- **Сбор измеряемых показателей**: loose objects (число и объем), pack-файлы, мусор (garbage, prune-packable), целостность объектов (`git fsck`).
- **Светофор и вердикт**:
  - 🟢 **Норма** (`NORMAL`): репозиторий компактен, обслуживание не требуется («Ничего не делать»).
  - 🟡 **Наблюдение** (`OBSERVATION`): накопление объектов или мусора («Повторить измерение / отслеживать динамику»).
  - 🔴 **Требуется обслуживание** (`MAINTENANCE`): превышен штатный порог Git GC («Запустить git gc --auto»).
- **Штатный запуск `git gc --auto`**: запуск оптимизации репозитория по встроенным критериям Git.
- **Журнал истории**: сохранение срезов диагностики и динамики метрик репозитория.
