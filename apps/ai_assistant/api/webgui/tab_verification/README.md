# Вкладка: Контур верификации и безопасности (tab_verification)

Вкладка отображает результаты проверок безопасности (Two-Stage Verification Pipeline), целостности Git и валидации фактов.

## Структура
- `panel_verification/`: Изолированная панель `panel-verification-pipeline`, взаимодействующая с `/v1/panel/panel-verification-pipeline`.
- `main.js`: Оркестратор вкладки.
- `index.html`: Разметка вкладки.
