## 📋 Описание модуля

Модуль интерфейса **«Чат ассистента»** (`tab_chat`) предоставляет интерактивный экран общения с локальными и облачными языковыми моделями в контексте текущего активного рабочего пространства.

Интерфейс поддерживает мультиязычные контекстные подсказки (Prompt Chips), переключение режимов ответа (локальные факты, темпоральный граф, Obsidian Vault), отображение источников цитирования и потоковый вывод ответов.

---

## 🎯 Основные возможности

1. **Контекстные быстрые подсказки (Prompt Chips)**:
   - Автоматическая динамическая генерация подсказок на основе коммитов Git, файлов, проиндексированных документов и сущностей базы знаний.
   - Поддержка языков: `ru`, `en`, `he`, `uk` с автоматическим fallback при пустой рабочей области.

2. **Интеграция с базой знаний и RAG**:
   - Вопросно-ответная система по фактам рабочего пространства через `KnowledgeQAEngine`.
   - Просмотр цитат источников и связанных сущностей.

3. **Синхронизация с активным пространством**:
   - Автоматическое обновление контекста чата при смене активного рабочего пространства.
   - Поддержка сценариев Telegram-бота и WebGUI.

---

## 🔌 API эндпоинты

- `GET /api/v1/workspaces/{workspace_id}/suggested-questions` — генерация контекстных быстрых подсказок по содержанию рабочей области.
- `POST /api/v1/qa/ask` — запрос к вопросно-ответной системе базы знаний.
- `GET /api/v1/workspaces/active` — получение текущей активной рабочей области.
