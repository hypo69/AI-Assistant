## 📋 Назначение

Вкладка **`tab_plugins`** предоставляет интерфейс для просмотра, включения/отключения, настройки и запуска плагинов из каталога [`plugins/`](../../../../plugins) (`system-plugins`, `user-plugins`, `developer-plugins`).

---

## 📂 Структура

- `index.html` — разметка каталога плагинов, карточек статуса и модального окна конфигурации.
- `main.js` — клиентский контроллер вкладки, взаимодействующий с маршрутами `/api/v1/plugins` ([`router_plugins.py`](../../routers/router_plugins.py)).

---

## 🔌 Используемые эндпоинты REST API

- `GET /api/v1/plugins` — список всех обнаруженных плагинов, их категорий, метаданных и текущего состояния;
- `POST /api/v1/plugins/{plugin_id}/toggle` — активация или деактивация плагина;
- `POST /api/v1/plugins/{plugin_id}/config` — сохранение параметров конфигурации плагина.
