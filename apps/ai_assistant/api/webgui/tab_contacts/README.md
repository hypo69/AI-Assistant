# Вкладка Google Контакты (`tab_contacts`)

Модуль веб-интерфейса для телефонной книги и адресной книги Google People API:
- Поиск контактов по имени, номеру телефона, email и организации.
- Отображение карточек контактов с аватарами и быстрыми ссылками (звонок, письмо).
- Добавление новых контактов с подробными атрибутами.
- Удаление контактов.
