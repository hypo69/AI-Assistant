# Вкладка: Темпоральный граф связей (tab_graph)

Вкладка отображает темпоральный граф связей кода (EvidenceLink) между коммитами и фактами с поддержкой окон валидности и инвалидации.

## Структура
- `panel_graph/`: Изолированная панель `panel-knowledge-links`, взаимодействующая с `/v1/panel/panel-knowledge-links`.
- `main.js`: Оркестратор вкладки.
- `index.html`: Разметка вкладки.
