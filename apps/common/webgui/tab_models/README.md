# Универсальная вкладка управления моделями ИИ и API-ключами (`apps/common/webgui/tab_models`)

## Назначение
Единый модуль управления активными моделями ИИ, переключения провайдеров (Google Gemini, Microsoft AI Foundry, ONNX / DirectML, Hugging Face, AGY, Ollama), тестирования генерации в реальном времени, управления пулом API-ключей и аккаунтами Google.
Используется совместно веб-интерфейсами экосистемы (**AI-Assistant** на `/#tab-models` и **AI-TC** на `/tc#tab-app-internals#models`).

---

## Возможности
- **Каталог моделей и провайдеров**: Выбор активной модели, фильтрация по провайдерам, сохранение в `config.json`.
- **Избранное и заметки**: Добавление моделей в быстрый доступ, быстрые чипы и локальные заметки к моделям.
- **Интерактивное тестирование**: Отправка тестовых промптов с замером времени ответа и возможностью отмены (`AbortController`).
- **Управление ключами Gemini и AGY**: Ротация ключей, визуализация статуса квот, проверка работоспособности в модальном окне, добавление, удаление и сброс суточных квот.
- **Управление аккаунтами Google**: Подключение, проверка статуса авторизации, переключение аккаунта по умолчанию.
- **Системные инструкции**: Просмотр и редактирование глобального системного промпта.
