## 📋 Назначение

Вкладка `tab_file_tree` предоставляет интерактивный интерфейс древовидного обзора файлов и поддиректорий рабочей области в стиле Visual Studio Code Explorer на базе общего сервиса [`apps/common/file_tree`](../../file_tree/README.md).

Вкладка расположена в общем репозитории ассетов `apps/common/webgui/tab_file_tree` и прозрачно раздаётся через `SmartMultiDirStaticFiles` по маршруту `/html/tab_file_tree/*`.

---

## 🧩 Возможности

1. **Иерархическое дерево каталогов и файлов**:
   - Отображение файлов и папок с иконками по типам расширений.
   - Чекбокс выбора возле каждого файла и папки с поддержкой каскадного выбора всех вложенных потомков.
   - Кнопки быстрого управления: «Выбрать все», «Снять выбор», «Инвертировать выбор», «Развернуть все», «Свернуть все».

2. **Навигация по директориям**:
   - Интерактивная цепочка хлебных крошек (`Breadcrumbs`) для возврата на любой уровень.
   - Кнопка перехода на уровень вверх (`..`).
   - Поле прямого ввода пути к директории и мгновенный переход.

3. **Контекстное подменю при правом клике (ПКМ)**:
   - **Кратко о файле**: всплывающее окно аналитической сводки (размер, число строк, язык VS Code, docstring / суть содержимого).
   - **Редактор**: открытие выбранного файла в универсальном Wasm-редакторе [`apps/common/webgui/tab_file_editor`](../tab_file_editor/README.md) через `window.openFileInWasmEditor()`.
   - **Создать новый**: создание файла или папки с коммитом в Git строго в той директории, где был совершён клик.
