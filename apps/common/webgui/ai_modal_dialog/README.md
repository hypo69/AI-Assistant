# Универсальное модальное окно с ИИ-анализатором (`ai_modal_dialog`)

Модуль `ai_modal_dialog` предоставляет универсальный компонент всплывающего окна для инспекции строк таблиц, аналитики сущностей Windows (процессы, службы, задачи, софт, драйверы, реестр) с интеграцией базы знаний WikiLLM и прямым вызовом LLM-анализатора.

### ⚡ Две изолированные базы данных:
1. **WikiLLM (`knowledge.db` / `wikillm_knowledge`)**:
   - Предназначена **для администратора**: объясняет суть изучаемого параметра, роли процессов, издателей, оценку безопасности, влияние на производительность и рекомендации.
   - Одобрение выполняется через кнопку «Одобрить в WikiLLM».
2. **AI Instruments (`ai_instruments.db` / `ai_instruments`)**:
   - Предназначена **ТОЛЬКО для агента**: хранит исключительно инструменты решения задач (PowerShell скрипты, вызовы утилит, параметры командной строки).
   - Сохранение выполняется через кнопку «В AI Instruments» на интерактивном терминале команды или кнопку «Сохранить в ai_instruments.db» в блоке советов разработчику.

### ⚡ Ключевые возможности и принципы:
1. **Терпеливое ожидание (No Timeout)**: клиент и сервер терпеливо ожидают ответа языковой модели без прерывания по таймауту.
2. **Честные ответы без подмены**: сервер не генерирует и не подставляет фиктивные эвристические карточки в случае сбоев или недоступности модели.
3. **Советы разработчику & Интерактивные скрипты (`developer_advice`)**: раскрывающийся блок с технической документацией (API, WinRT/COM/WinAPI, ключи реестра, WMI) и готовыми исполняемыми скриптами PowerShell/CMD/Python с возможностью запуска прямо из карточки.
4. **Безопасность и кэш WikiLLM**: проверенные знания и сценарии автоматизации сохраняются в WikiLLM (L1 Exact Cache O(1)). При получении ошибки модели запись в базу знаний WikiLLM строго блокируется.
5. **Информативная диагностика ошибок**: пользователю возвращается расшифрованное сообщение об ошибке (квоты, ключи, недоступность сервиса) вместе с сырым JSON-ответом от модели для удобной отладки.

## 💻 API JavaScript

Компонент экспортирует глобальные объекты:
- `window.AIModalDialog` (основной)
- `window.AITableModal` (для обратной совместимости)

### Вызов всплывающего окна: `window.AIModalDialog.show(options)`

```js
window.AIModalDialog.show({
  title: 'svchost.exe',
  subtitle: 'PID: 1042',
  icon: '⚙️',
  tableType: 'process',
  badges: [
    { text: 'System', class: 'badge bg-primary' },
    { text: 'Active', class: 'badge bg-success' }
  ],
  metadata: [
    { label: 'Исполняемый путь', value: 'C:\\Windows\\System32\\svchost.exe', isCode: true },
    { label: 'Память', value: '45.2 MB' },
    { label: 'CPU', value: '0.4%' }
  ],
  rawTitle: 'Командная строка запуска',
  rawContent: 'C:\\Windows\\System32\\svchost.exe -k netsvcs -p -s Schedule',
  autoRun: false, // Автоматический запуск генерации AI (по умолчанию false - сначала проверка WikiLLM)
  actions: [
    {
      label: 'Завершить процесс',
      icon: 'bi-x-circle',
      class: 'btn-outline-danger',
      onClick: (opts) => { console.log('Kill', opts); }
    }
  ]
});
```

### Редактор промптов: `window.AIModalDialog.openPromptEditor(tableType)`

Открывает встроенный редактор шаблонов системных инструкций и промптов для указанного типа сущности (`process`, `service`, `software`, `task`, `network`, `registry`, `user`, `website`, `generic`).

## 🖥️ Интерактивный терминал выполнения команд (`.uai-terminal-window`)

Карточки инструментов решений (`renderReadyToolWidget`) и блоки кода PowerShell (`renderInteractiveCommandWidget`) содержат встроенную консоль:

- **Уникальные ID в DOM**: Каждый экземпляр терминала получает детерминированный идентификатор `uai-term-<id>`, а все дочерние элементы оснащены соответствующими ID:
  - `#<id>` — контейнер окна терминала `.uai-terminal-window`;
  - `#<id>-title` — заголовок и иконка консоли;
  - `#<id>-btn-settings` — кнопка переключения панели настроек;
  - `#<id>-settings-panel` — панель параметров выполнения;
  - `#<id>-opt-shell` — выбор оболочки (`PowerShell`, `PowerShell Core (pwsh)`, `CMD`);
  - `#<id>-opt-timeout` — таймаут выполнения (15с, 30с, 35с, 60с, 120с);
  - `#<id>-opt-admin` — переключатель запуска с правами Администратора (`RunAs`);
  - `#<id>-opt-wrap` — переключатель переноса длинных строк (Word Wrap);
  - `#<id>-btn-clear` — кнопка очистки поля ввода и вывода;
  - `#<id>-input` — текстовое поле ввода команды (`.uai-cmd-input`);
  - `#<id>-btn-copy` — кнопка копирования команды в буфер обмена;
  - `#<id>-btn-run` — кнопка отправки команды на исполнение;
  - `#<id>-output-container`, `#<id>-result-badge`, `#<id>-output` — контейнер и блок вывода результата.

- **Выполнение через API**: POST `/api/v1/diagnostics/execute-powershell` с поддержкой параметров `shell`, `timeout_sec`, `as_admin`.
