# Common WebGUI Framework (Общие веб-решения и ассеты)

Единый репозиторий общих стилей, токенов дизайн-системы, тем оформления, интернационализации (i18n) и базовых клиентских компонентов для всех веб-приложений проекта AI Windows Admin (включая `apps/windows` и `apps/ai_assistant`).

---

## 📁 Структура каталога

- **`css/`**: Токены тем оформления и базовые таблицы стилей:
  - `variables.css`: Сквозные CSS-переменные дизайн-системы (цвета, фоны, радиусы, шрифты, отступы).
  - `themes.css`: Стили и модификаторы цветовых схем (`[data-theme="..."]`).
  - `base.css`: Сброс стилей, базовые элементы HTML и типографика.
  - `components.css`: Унифицированные компоненты (карточки, модальные окна, таблицы, бейджи, кнопки).
  - `nav.css`: Стилизация панели навигации и таб-бара.
  - `chat.css`: Стилизация интерфейса интерактивного AI-чата.
  - `global-overrides.css`, `overrides.css`: Сквозные переопределения и адаптивные правила.

- **`themes/`**:
  - `themes_catalog.json`: Машинночитаемый реестр всех зарегистрированных тем с описаниями и превью.
  - `generate_themes_catalog.py`: Утилита валидации и генерации каталога тем.

- **`js/`**: Инфраструктурные клиентские модули:
  - `global-i18n.js`: Фреймворк клиентской локализации с автоопределением языка и мутационным наблюдателем.
  - `i18n.js`: Вспомогательные функции интернационализации.
  - `global-tooltips-i18n.js`: Мультиязычная база всплывающих подсказок и хелперов.
  - `theme.js`: Управление текущей темой (чтение/сохранение в `localStorage`).
  - `theme-engine.js`: Продвинутый движок динамических тем, расчёта контраста и экспорта.
  - `tab-core.js`: Базовый класс и ядро жизненного цикла вкладок.
  - `panel-loader.js`: Динамическая подгрузка HTML/JS-панелей вкладок.
  - `toast.js`: Всплывающие уведомления (Toast).
  - `activityTracker.js`: Мониторинг пользовательской активности.
  - `api-cache.js`, `cache-ui.js`: Модули кеширования запросов и интерфейса.

- **`locales/`**: Базовые словари интернационализации:
  - `ru.json`, `en.json`, `he.json`, `uk.json`: Базовые ключи общих элементов (`common`, `tabs`, `userSettings`, `cacheManager`, `helpModal`).

- **`ai_modal_dialog/`**: Универсальное модальное окно AI-анализатора данных (`#universal-ai-table-modal`):
  - Полноэкранный режим, подсветка синтаксиса, навигация по истории, экспорт и фиксация фокуса.

- **`tab_theme_editor/`**: Встроенный интерактивный редактор тем оформления:
  - Панели пресетов, токенов, предпросмотра и экспорта.

- **`tab_file_editor/`**: Универсальный редактор файлов на базе Rust + WebAssembly:
  - Редактирование всех типов файлов Visual Studio Code (70+ языков кода, Markdown Split-View, таблицы CSV/TSV, блокноты Jupyter `.ipynb`, векторная графика SVG, растровые изображения, PDF и бинарный Hex-редактор с Data Inspector).

- **`components/`**:
  - `universal_ai_table_modal.html`: Декларативная разметка модального окна.

## 🚀 Использование в FastAPI сервисах

Для подключения каскадной раздачи статики (с динамическим fallback на общий каталог `apps/common/webgui`) используется класс `SmartMultiDirStaticFiles`:

```python
from apps.common.webgui import SmartMultiDirStaticFiles, COMMON_WEBGUI_DIR

# Раздача статики с приоритетом локальных файлов приложения и fallback на общие:
app.mount(
    "/html",
    SmartMultiDirStaticFiles(APP_WEBGUI_DIR, COMMON_WEBGUI_DIR),
    name="app-html"
)
```

При этом:
1. Если файл запрошен и найден в `APP_WEBGUI_DIR` — сервер отдаёт локальную версию приложения.
2. Если локальный файл отсутствует (например, общие темы, CSS-переменные или ядро i18n) — сервер прозрачно отдаёт файл из `apps/common/webgui`.
