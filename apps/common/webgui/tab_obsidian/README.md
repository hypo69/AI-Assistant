# Вкладка базы знаний Obsidian (apps/common/webgui/tab_obsidian)

## Описание

Полнофункциональный веб-интерфейс персональной базы знаний и заметок в стиле **Obsidian**.
Построен по единой компонентной архитектуре с `tab_file_editor` и `tab_file_tree`.

## Возможности интерфейса

1. **Верхняя панель инструментов и статистика (Vault Summary)**:
   - Аналитические бейджи: количество заметок, связей, уникальных тегов и заметок-сирот.
   - Переключатель режимов отображения:
     - *Редактор (Edit)*: полноэкранное написание Markdown текста.
     - *Раздельный вид (Split)*: синхронный редактор и интерактивный предпросмотр.
     - *Просмотр (Preview)*: чистый рендеринг документа.
     - *Граф знаний (Graph)*: полноэкранная интерактивная 2D карта связей заметок на Canvas.
   - Кнопка создания новой заметки и быстрая генерация ежедневных заметок (Daily Notes: `YYYY-MM-DD.md`).
2. **Панель Markdown инструментов**:
   - Быстрая вставка заголовков (H1, H2, H3), жирного, курсива, цитат, блоков кода, таблиц и формул LaTeX.
   - Вставка вики-ссылок `[[...]]`, тегов `#тег`, блоков Obsidian Callout (`> [!NOTE]`) и задач (`- [ ]`).
3. **Левая панель навигатора хранилища**:
   - Полнотекстовый поиск по содержимому и названиям заметок.
   - Интерактивное облако тегов для быстрой фильтрации заметок.
   - Список заметок со счетчиками обратных связей и количества слов.
4. **Центральная рабочая область**:
   - Редактор с поддержкой горячих клавиш (`Ctrl+S`).
   - Split-предпросмотр с интерактивными кликабельными вики-ссылками (переход к заметке или предложение создать, если не существует).
   - Интерактивные чекбоксы задач: переключение галочки в предпросмотре мгновенно обновляет текст в редакторе и сохраняет изменения.
   - Блоки Obsidian Callout со стилизацией через CSS-переменные активной темы.
5. **Интерактивный 2D Граф связей (`panel_graph_view.js`)**:
   - Визуализация взаимосвязей заметок на HTML5 Canvas с поддержкой зума, панорамирования (pan & drag) и перехода к заметке по клику на узел.
6. **Инспектор связей (`panel_backlinks.js`)**:
   - Входящие обратные ссылки (Backlinks) с контекстными фрагментами текста.
   - Неразмеченные упоминания (Unlinked Mentions) заголовка заметки с кнопкой «Связать» в один клик.
   - Список исходящих связей (Outgoing links).

## Файловая структура

- `index.html` — разметка интерфейса вкладки.
- `style.css` — таблица стилей на CSS-переменных (без хардкода HEX/RGB).
- `main.js` — главный оркестратор вкладки.
- `panel_graph_view.js` — модуль интерактивного 2D-графа на Canvas.
- `panel_backlinks.js` — модуль инспектора обратных ссылок и неразмеченных упоминаний.
