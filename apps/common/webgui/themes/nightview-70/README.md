# NightView 70% (Тёплая бумага 70%)

Компактная тема NightView 70% на 100% рабочей площади экрана. Сохраняет всю мягкую палитру тёплой бумаги NightView (`#ede6d9`, `#f6f1e8`, `#e2dac9`), заполняя всю ширину и высоту дисплея без пустых полей и без использования `zoom: 0.7`.

## Особенности
- **100% использование экрана**: Верстка занимает полную ширину и высоту экрана, отсутствуют неиспользуемые 30% области.
- **Компактная типографика**: Базовый шрифт уменьшен до 11px (~70%), заголовки панелей 1.15rem вместо 1.75rem.
- **Компактные таблицы и элементы**: Уменьшенные паддинги строк таблиц (0.22rem), инпутов и кнопок позволяют отображать на 30-40% больше полезных данных.
- **Модальные окна**: Сохраняют полноценный габарит 90% экрана (`90vw × 90vh`) с компактной организацией содержимого.
