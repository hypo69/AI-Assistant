# 🐙 Вкладка GitHub Issues & Projects (`tab_issues`)

**Updated:** 2026-11-03 14:41:44  
**Автор:** hypo69  
**Пакет:** `apps.common.webgui.tab_issues`  

## 🎯 Назначение

Глобальная вкладка `tab_issues` предоставляет полноценный визуальный интерфейс для управления задачами GitHub Issues, досками проектов, вехами Milestones и контекстом локального Git-репозитория в рамках экосистемы AI Windows Admin.

Она реализует парадигму **Issue-driven AI Development**, превращая GitHub Issues в визуальное рабочее место как для разработчика/администратора, так и для автономных AI-агентов.

---

## 🏛️ Ключевой функционал

1. **Контекст Git-репозитория:**
   - Отображает текущий удаленный репозиторий (`remote.origin.url`, например `https://github.com/hypo69/AI-TC.git`).
   - Имя репозитория (`hypo69/AI-TC`).
   - Активную Git-ветку (`master` / `main`).
   - Хеш и сообщение последнего коммита.
   - Чистоту рабочей директории (есть ли незафиксированные изменения).
   - Статус авторизации GitHub CLI (`gh`).

2. **Список задач и фильтрация:**
   - Таблица задач с номерами, статусами (`Open`/`Closed`), типами, приоритетами, компонентами и исполнителями.
   - Быстрый поиск по названию, номеру или описанию.
   - Фильтры по состоянию, типу (`bug`, `feature`, `enhancement`...), компоненту AI-TC (`telemetry`, `windows`, `network`, `gui`, `ai`, `mcp`, `core`).
   - KPI метрики: общее количество, открытые, закрытые, ошибки, новые функции, критические задачи.

3. **Создание задач со всеми параметрами:**
   - Выбор стандартных шаблонов задач (`bug_report.md`, `feature_request.md`, `enhancement.md`, `documentation.md`, `refactoring.md`, `research.md`).
   - Автоматическое заполнение Markdown-структуры шаблона.
   - Выбор типа, приоритета, компонента AI-TC и исполнителя.
   - Публикация задачи на GitHub через API.

4. **Интеграция с автономным AI-разработчиком:**
   - Создание изолированной ветки Git (`fix/<num>-<slug>` или `feat/<num>-<slug>`) в один клик.
   - Генерация структурированного ТЗ для AI (`AITaskPlan`) с перечнем целевых файлов и проверочных сценариев.
   - Формирование Pull Request с директивой автоматического закрытия (`Fixes #<num>`).

5. **Вехи и метки:**
   - Прогресс-бары выполнения релизов (Milestones).
   - Каталог стандартных меток AI-TC с возможностью синхронизации в репозиторий через `gh`.
