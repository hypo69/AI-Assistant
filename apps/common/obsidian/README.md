# Модуль базы знаний Obsidian (apps/common/obsidian)

## Описание

Модуль предоставляет полнофункциональную среду локальной базы знаний и заметок в стиле **Obsidian** для AI-Assistant.
Построен по единым стандартам и архитектурным паттернам модулей `apps/common/file_editor` и `apps/common/file_tree`.

## Возможности

1. **Индексирование хранилища (Vault)**:
   - Автоматическое сканирование Markdown-заметок (`.md`) в активном рабочем пространстве.
   - Подсчет общего количества заметок, связей, уникальных тегов и слов.
   - Выявление заметок-сирот (orphan notes), не имеющих входящих или исходящих связей.
2. **Парсинг и метаданные**:
   - Чтение и разбор блоков YAML Frontmatter (`tags`, `title`, `date`, кастомные свойства).
   - Поддержка вики-ссылок `[[Название Заметки]]` и `[[Название|Алиас]]`.
   - Тегирование заметок `#тег` в теле и свойствах.
   - Obsidian Callouts (`> [!NOTE]`, `> [!WARNING]`, `> [!TIP]`, `> [!IMPORTANT]` и др.).
   - Интерактивные чекбоксы задач (`- [ ]` и `- [x]`).
3. **Интерактивный 2D Граф связей (Graph View)**:
   - Построение узлов (заметки) и связей (wikilinks).
   - Масштабирование размера узлов в зависимости от количества входящих обратных ссылок.
   - Цветовая группировка по тегам и папкам.
4. **Инспектор связей (Backlinks Inspector)**:
   - Полный список входящих обратных ссылок с контекстными сниппетами.
   - Обнаружение неразмеченных упоминаний (Unlinked Mentions) заголовка заметки.
   - Список исходящих ссылок.
5. **Создание и версионирование**:
   - Создание новых заметок в указанных каталогах.
   - Создание ежедневных заметок (Daily notes: `YYYY-MM-DD.md`) по шаблону.
   - Сохранение с автоматической фиксацией коммитов в Git.
6. **Повторное использование кода (DRY)**:
   - Общий резолвер путей и рабочих пространств вынесен в `apps/common/workspace_resolver.py` и совместно используется `file_editor`, `file_tree` и `obsidian`.

## Структура пакета

- `models.py` — Pydantic модели запросов, сводок, узлов графа и заметок.
- `service.py` — бизнес-логика индексирования, парсинга Markdown, построения графа и связей.
- `router.py` — FastAPI роутер `/api/v1/obsidian/*`.
- `__init__.py` — экспорт публичного API модуля.
