## 📋 Назначение

Модуль `apps/common/file_tree` предоставляет единый высокопроизводительный сервис и REST API для интерактивной навигации по файловой структуре выбранной директории рабочей области:

1. **Иерархическое дерево каталогов и файлов**:
   - Построение дерева поддиректорий с чекбоксами выбора возле каждого файла и папки.
   - Поддержка каскадного выбора (выбор папки выделяет всех её потомков).
   - Быстрый выбор/снятие выбора всех элементов одной кнопкой.

2. **Навигация по директориям**:
   - Интерактивные хлебные крошки (`Breadcrumbs`) для быстрого возврата на любой уровень.
   - Кнопка перехода на уровень вверх (`..`).
   - Поле ввода относительного пути и выпадающий список доступных папок.

3. **Интерактивное контекстное подменю (ПКМ)**:
   - **Кратко о файле**: мгновенная аналитическая сводка (размер, число строк, детекция языка VS Code, извлечение описания/docstring).
   - **Редактор**: бесшовное открытие файла в универсальном Wasm-редакторе [`apps/common/webgui/tab_file_editor`](../webgui/tab_file_editor/README.md).
   - **Создать новый**: создание нового файла или каталога строго в той директории, где был совершен клик.

## 🔌 Контракты REST API (`/api/v1/file-tree`)

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/api/v1/file-tree/browse` | Сканирует выбранную директорию и возвращает дерево с хлебными крошками |
| `GET` | `/api/v1/file-tree/summary` | Возвращает краткую аналитическую сводку по файлу для контекстного меню |
| `POST` | `/api/v1/file-tree/create` | Создаёт файл или подпапку в целевой директории с фиксацией в Git |
| `GET` | `/api/v1/file-tree/directories` | Возвращает список доступных директорий для навигации |
